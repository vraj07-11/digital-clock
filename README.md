# 🕒 Digital Clock

A sleek and modern digital clock web application featuring a stunning UI with a vibrant, colorful glow effect. Built with vanilla web technologies to display accurate real-time updates with an aesthetic visual flair.

## ✨ Features

- **Real-Time Clock:** Displays current hours, minutes, and seconds accurately.
- **Colorful Glow Effect:** Eye-catching, ambient neon lighting styling that enhances the modern look.
- **Dynamic UI:** Smooth second-by-second updates with a clean layout.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Advanced Glow Styling / Animations), Vanilla JavaScript
- **Version Control:** Git & GitHub
